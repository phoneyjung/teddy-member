# Teddy Member — ระบบสมาชิกเครดิต Teddy 1 + Teddy 2

- หน้าลูกค้า (เช็กยอด): https://phoneyjung.github.io/teddy-member/
- หน้าแอดมิน: https://phoneyjung.github.io/teddy-member/admin.html
- API: Cloudflare Worker `teddy-member` + D1 (โค้ด Worker ไม่อยู่ใน repo นี้ — อยู่ในโปรเจกต์ร้านซักผ้า)

ไฟล์ในนี้เป็นหน้าเว็บล้วน ไม่มีรหัสผ่าน คีย์ หรือข้อมูลสมาชิก — ห้ามอัปไฟล์นำเข้า (teddy-member-import.json) หรือไฟล์ PIN ขึ้น repo นี้
ถ้าเปลี่ยนชื่อ Worker ให้แก้ `config.js` บรรทัดเดียว
